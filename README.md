Project Overview
 This project focuses on analyzing Human Resources data to understand employee attrition, workforce distribution, salary trends, and employee satisfaction.

 The objective is to gain meaningful insights from employee data and support better HR decision-making.

Dataset
- Total Records: 1,470 employees
- Total Features: 37 columns
- File Format: Excel (.xlsx)

Key Analysis
- Employee distribution by department
- Employee attrition analysis
- Monthly income analysis
- Age and gender distribution
- Job satisfaction analysis
- Work-life balance analysis
- Years of experience and employee retention

Tools Used
- Microsoft Excel
- Data Analysis
- Data Visualization

Project Files
- HR_Analytics.xlsx – HR dataset and analysis

Project Objective
To identify employee attrition patterns and understand the factors influencing employee retention and workforce performance.
